01 / PROJECT INTRODUCTION

10초 인형뽑기란?

10초 인형뽑기는 사용자가 앱인벤터를 통해 원하는 시간을 설정하고, 터치센서로 게임을 시작한 뒤 설정된 시간에 정확히 버튼을 눌러 인형을 획득하는 게임형 프로젝트입니다. LCD에 표시되는 경과 시간을 확인하며 목표 시간을 맞추는 것이 핵심입니다.

📱

앱인벤터 시간 설정

MIT 앱인벤터를 활용해 게임의 목표 시간을 직접 설정하고 제어 시스템에 전달합니다.

⏱️

실시간 시간 측정

터치센서를 누르면 게임이 시작되며, LCD에 0초부터 경과 시간이 표시됩니다.

🧸

정확한 타이밍 도전

앱에서 설정한 목표 시간에 정확히 버튼을 누르면 서보모터가 작동해 인형을 획득할 수 있습니다.

02 / OPERATING PROCESS

HOW IT WORKS

앱인벤터부터 서보모터까지 이어지는 게임 작동 과정입니다.

01

시간 설정

앱인벤터에서 목표 시간을 설정합니다.

02

게임 시작

터치센서를 누르면 게임이 시작됩니다.

03

시간 카운트

LCD에 0초부터 경과 시간이 실시간으로 표시됩니다.

04

버튼 입력

설정한 목표 시간과 정확히 일치하는 순간 버튼을 누릅니다.

05

인형 획득

성공하면 서보모터가 문을 열어 인형을 가져갈 수 있습니다.

04 / MAIN FEATURES

PROJECT POINT

01. 사용자 맞춤 시간 설정

앱인벤터를 통해 사용자가 원하는 목표 시간을 설정할 수 있어 다양한 시간 조건으로 게임을 진행할 수 있습니다.

02. 터치센서 기반 게임 시작

터치센서 입력을 시작 신호로 활용하여 사용자가 직접 게임을 시작할 수 있도록 구성했습니다.

03. LCD 실시간 시간 표시

게임 시작과 동시에 0초부터 경과 시간을 LCD에 표시하여 사용자가 현재 시간을 확인할 수 있습니다.

04. 서보모터 자동 문 개방

설정한 목표 시간과 버튼 입력 시간이 일치하면 서보모터를 작동시켜 인형 보관함의 문을 개방합니다.
